# Tiny Stack VM

Interpreter for make.fun's tiny stack ISA v1: wrapping 32-bit arithmetic,
signed/unsigned division and comparisons, masked shifts, 256-word memory,
64-deep calls, all ten traps with their exit codes.

Run (Node 22): `MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts`
